# Stimulus Audio

Place the NMED-E intact/original Elgar stimulus audio here as:

```text
nmed_e_original.wav
```

The target stimulus is the intact excerpt used as NMED-E stimulus 22. The existing derived EEG/engagement table in this project contains 95 complete 5 s windows from 0-475 s, so the analysis scripts use the first 475 s of the audio for window alignment. The NMED-E repository does not redistribute the stimulus audio directly; its README says to contact the dataset author for stimulus audio access.

Do not commit or redistribute audio files in this folder.
